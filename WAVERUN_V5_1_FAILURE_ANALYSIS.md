# WAVERUN V5.1 Failure Analysis

The dominant failure is regime transfer: apparent `$100` precision near 70% in Q1/Apr-Jun falls to approximately 50% in Jul-2026. High nominal precision is accompanied by median MAE around -$190 to -$237 and hundreds of signals/day, so it is not a tradable product edge.

Pressure continuation and Spot/Futures confirmation were nearly indistinguishable in this tier. That is evidence that the available agreement feature did not add independent discrimination. MACD interaction also did not improve the Jul fold. Absorption and mean-reversion families reduced frequency somewhat but remained far above the product target and did not stabilize precision.

The missing historical Vantage path prevents a genuine bid/ask execution conclusion; the $17 cost is a declared proxy only. No L2, Coinbase, OI or liquidation blocker was credited with value when absent.
